# Reference Sites — Visual & Technical Research

Les références sont des sources d'inspiration, pas des modèles à copier. Les détails techniques doivent être vérifiés sur les sites ou études de cas avant d'en déduire une architecture.

## 1. Site actuel Lumicrea
URL : https://1w51c1-tt.myshopify.com/

À observer :
- produits réels et collection Vendôme ;
- noms des finitions ;
- ton actuel de la marque ;
- réalisations et visuels autorisés ;
- parcours vers le configurateur.

À ne pas reproduire automatiquement :
- la hiérarchie actuelle de la page ;
- les répétitions de produits ;
- les textes de thème génériques ;
- les libellés mélangés en français et en anglais.

## 2. Tabasco — Hilo Studio
URL : https://tabasco.hilostudiolab.com/
Étude de cas : https://hilostudiolab.com/en/projects/tabasco

À étudier :
- narration par scroll ;
- synchronisation entre scènes 3D et contenu ;
- rythme des révélations ;
- comportement responsive.

À adapter :
- remplacer la narration de marque alimentaire par une narration sur la forme, la matière et les finitions d'appareillage électrique.

## 3. VEIL — D-LAB
URL : https://clothing-brand-three-kappa.vercel.app/
Étude de cas : https://d-lab.codes/experiments/veil

À étudier :
- direction artistique sombre et éditoriale ;
- typographie et composition ;
- intégration des animations dans le parcours.

À adapter :
- conserver une esthétique moins agressive et plus architecturale, pertinente pour un produit de décoration intérieure.

## 4. DeepSee Commerce — Hon Tran
Étude de cas : https://www.hontran.dev/blog/deepsee-commerce-3d-ecommerce-website-case-study

À étudier :
- rapport entre immersion et objectif commercial ;
- limites de performance ;
- façon dont une métaphore visuelle structure l'expérience.

## 5. Valentin Gassend
URL : https://valentingassend.com/en/

À étudier :
- interactions de creative developer ;
- transitions et détails ;
- cohérence entre le concept et les techniques employées.

## 6. Awwwards 3D — collection GitHub
URL : https://github.com/tsogjavklann/awwwards-3d

À étudier :
- exemples et liens de sites 3D ;
- techniques de scène, caméra et animation ;
- pistes d'expérimentation.

## Grille d'analyse à remplir pour chaque référence
- Quelle est la première impression ?
- Quel élément est le point focal ?
- Quel est le rôle de la 3D : démonstration, ambiance, narration ou navigation ?
- À quel moment la caméra bouge-t-elle ?
- Qu'est-ce qui déclenche les animations ?
- Comment le site se comporte-t-il sur mobile ?
- Quel est le fallback en cas de performance insuffisante ?
- Quelles idées peut-on adapter sans copier le design ?
